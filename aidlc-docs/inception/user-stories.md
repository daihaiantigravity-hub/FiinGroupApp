# User Stories — Application Platform

- As a developer, I can start the frontend and backend from documented commands so that onboarding is repeatable.
- As a developer, I can call a typed new API client so that frontend modules do not duplicate request logic.
- As an operator, I can check service health without exposing credentials or sensitive data.
- As an architect, I can distinguish legacy API calls from `/api/v2` calls so that migration can happen incrementally.
- As a reviewer, I can inspect AI-DLC decisions and test evidence in the repository before approving the next unit.
