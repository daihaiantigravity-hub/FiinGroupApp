# Workflow Planning

## Execution order

1. Revalidate imported legacy baseline.
2. Complete requirements, stories, NFR and security decisions.
3. Approve Application Platform design.
4. Construct the React/.NET platform.
5. Build, test and review.
6. Record the checkpoint and select the next unit.

## Units of Work

1. Application Platform
2. Authentication and user profile
3. Shared UI/data components
4. Dashboard
5. Wiki, documents and announcements
6. Project management
7. Approval workflow
8. HR
9. Salary and finance
10. Chatbot
11. TFS, email workers and integrations
12. Deployment and operations

## Gate

Construction for a feature unit requires approved requirements, API contracts, permission mapping, data impact, test plan and rollback instructions.
